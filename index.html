PREPARATION · STEP BY STEP

Pinecone：從零建立向量資料庫

跟著小葵準備第一個 AI 搜查基地。建議使用測試資料，先完成 Dense Index，再進行 Hybrid 延伸。

申請 Pinecone 帳號

開啟 Pinecone 官方網站 ↗，點選 Sign Up / Get Started，使用可用的電子郵件或登入方式建立帳號，完成驗證並進入 Console。免費 Starter 方案有使用限制，請在建立資源前確認當前價格與額度。

建立 Project 並取得 API Key

在 Console 確認目前的 Organization / Project，進入 API Keys，建立或複製 API Key。只放在 n8n 的 Credentials，**不要寫進 Code 節點、網站 HTML 或分享的 Workflow JSON**。

建立 Dense Index

選擇 Create Index，教學建議命名 rag-basic-lab。選擇支援的 Serverless 區域，建立 Dense Vector Index。若使用 n8n 的外部 Embeddings 節點，應選擇自行提供向量的索引模式，並設定與 Embedding 模型一致的 Dimension（例如 1536 僅適用於輸出 1536 維的模型）、Metric 建議 cosine。

注意：Pinecone 的「整合式 Embedding Index」與「自行提供向量的 Index」是不同設定路線；本課採用後者，以便觀察 n8n 的 Embeddings 節點。

在 n8n 建立 Pinecone Credential

開啟 n8n → Credentials → New → Pinecone，貼入 API Key 並儲存。接著新增 Pinecone Vector Store 節點，選取 Credential、Index rag-basic-lab、Namespace training（依版本可用選項設定）。

驗證索引與維度

在 Pinecone Console 檢查 Index Ready；先寫入一份小型測試文件，再查詢指定句子。若報錯，優先檢查 Index 名稱、API Key 所屬 Project、Dimension、Namespace 與 Embedding 模型是否一致。

Hybrid 準備：Dense + Sparse 兩路

本課採「兩路檢索後在 n8n 合併」：原有 Dense Index 加上獨立 Sparse Index。Sparse Index 必須使用對應的 Sparse Vector/Embedding 方案（例如 Pinecone 支援的 Sparse 服務或可用 API），不能把 Dense Index 改名當作 Sparse 使用。請先確認方案、模型與 API 的當前支援及費用。

注意：n8n 的 Pinecone Vector Store 節點主要用於 Dense RAG 教學。Sparse 路線可能需使用 HTTP Request 呼叫 Pinecone API；並非每個版本都能用同一個 Pinecone 節點完成 Hybrid。

PROMPT-TO-WORKFLOW · n8n + PINECONE

n8n AI 工作流生成教室

每個動作都提供可直接複製到 ChatGPT 的完整 Prompt。學生先理解階段，再要求 ChatGPT 產生可匯入 n8n 的 JSON，匯入後逐節點檢查、設定憑證與執行測試。請勿在 Prompt 中填入真實 API Key。

重要：AI 生成的 JSON 不保證能直接執行。需依 n8n 實際版本檢查節點 type、typeVersion、連線與 Pinecone API 功能；敏感憑證應在 n8n Credentials 中設定。Hybrid Sparse API 是否可用，取決於 Pinecone Index 類型及所選模型。
